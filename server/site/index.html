Tainted

A dark action RPG. Play the campaign, run rifts and meet other players in the town. Free.

Windows
Tainted.exe, about 170 MB↓ Android
Tainted.apk, about 105 MB↓

Getting started

  1. Install it (below), then open the game.
  2. On the sign-in screen pick Create an account. It opens a page in your browser: it is free, and you only need an email address and a password of at least 12 characters.
  3. Come back to the game and sign in with the same email and password. Make a character and you are in.

Installing

  • Windows: run Tainted.exe. If Windows says it protected your PC, choose More info, then Run anyway. Nothing else needs installing.
  • Android: open the downloaded Tainted.apk. Android will ask you to allow installs from your browser or files app; allow it for this once, then install.

Updates

The game updates itself when you connect, so you only ever download it once.

Your Tainted account is your own: Delete account on the character screen removes your characters and the sign-in with them.

# Assets

Drop downloaded art here, keeping each pack in its own folder:

    assets/kenney/<pack-name>/...
    assets/itch/<author>-<pack-name>/...

Kenney packs are CC0 (kenney.nl/assets). Good starting points to search for:
Tiny Dungeon, Roguelike Characters, Roguelike Caves & Dungeons, Roguelike RPG Pack, UI Pack, Game Icons.

itch.io: filter by "top-down" + "dungeon" and check each pack's license before shipping.
Note credits for anything that requires attribution.

Pixel-art import settings in Godot: select the PNGs, Import tab -> Preset "2D Pixel"
(turns off filtering so sprites stay sharp), then click Reimport.
